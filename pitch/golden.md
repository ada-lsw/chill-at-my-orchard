Stations 32, 270 have both files but no data from both sources in these winters, so they are not counted. Stations 6, 7 have an FNRIC file but no CIMIS hourly file saved, so they are not counted either.

A complete day has 24 real hourly readings in our CIMIS data (none missing, none filled by our gap filler) and a non-empty row in FNRIC's daily file. CIMIS times are hour-ending; each reading is counted in the day it ends in, so the 24:00 reading belongs to the day it closes (stored by `data.py` as 00:00 of the next day). Check of that rule: counting the 24:00 reading in the next day instead matches on 79.5% of 19,923 of the same days.
